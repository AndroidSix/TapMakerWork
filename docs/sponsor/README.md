## 替换图片

1. 在微信 / 支付宝生成**收款码**（不要用付款码）。
2. 裁剪至二维码区域，导出 PNG。
3. **覆盖**上表对应文件名，保持路径不变。
4. 提交到 **Gitee 主仓**；GitHub 镜像随推送同步。

## 注意

- 赞助自愿，**与软件功能、MIT 授权无关**。
- 请使用可公开的收款码截图，避免无关隐私信息。
- 公开仓库中收款码可被任何人查看；若改为仅外链赞助，可删除 README 中图片引用。
- 换码后历史提交中可能仍留有旧图，请及时停用旧收款码。
